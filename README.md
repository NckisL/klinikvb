# Clinic Data Management Application

## About
This is a desktop application for managing the daily data of a small clinic. It lets clinic staff record patients and their visits, assign each visit to a doctor, and see the treatment fee automatically based on the type of treatment (outpatient, inpatient, referral, or consultation, with or without insurance). Doctor data can also be managed in the same application.

All data is stored in a MySQL database. The main screen shows each visit together with the patient, doctor, and fee in one table, so staff can quickly look up, edit, or delete records.

Built with VB.NET (Windows Forms) as a coursework project in 2023.

## Features
Add, edit, and delete patient visit records
Add, edit, and delete doctor data
View visit data with patient, doctor, and treatment fee in one table (SQL JOIN)
Auto-generated IDs, input validation, and confirmation dialogs

## Tech Stack
VB.NET, Windows Forms, MySQL
